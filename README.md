# FuoEvolve9 for iOS 9

A FeelUOwn-inspired music player for iPhone 4S running iOS 9.3.6, built with Theos.

## Features
- Home screen with navigation
- Music search interface
- Music player UI
- Optimized for iOS 9 / armv7

## Build
This project is designed to be built with the ios9-port-release pipeline.
